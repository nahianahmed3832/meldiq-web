# Smooth loading, sign-in and separate purchases — 1 November 2026

This release follows the latest-message and mobile screen-viewing fixes and preserves the live PayPal Plus release.

- Password + verified authenticator or single-use backup code establishes session-bound assurance for ten minutes. The same fresh session can unlock its password-encrypted backup without another email OTP. Password-only sessions, older sessions, and expired assurance still require the existing email step. Initial email ownership verification, session binding and single-use recovery remain enforced. Refresh preserves the original proof time.
- Chat history begins loading alongside summaries. Historical sender profiles hydrate in the background instead of blocking each message. Read markers still arrive before the window becomes ready or can acknowledge messages. Local restore reads run together; frequent events no longer postpone snapshots indefinitely. The signed-in shell is split out of sign-in JavaScript and prefetched when restoring an existing device.
- Mojo Plus remains USD 3.99/month. Bots+ is a separate USD 3.99/month subscription for one community, purchased by an owner and canceled by its payer. No personal Plus purchase is required.
- A purchased Spark costs USD 0.99 once, with quantities 1–20. It is a durable slot, usable in one community at a time and movable using existing cooldown rules. No automatic renewal or personal Plus requirement. Included Plus Sparks and existing recurring Spark subscriptions retain their entitlement rules. Full refunds/reversals revoke purchased slots; assignments beyond the balance pause through the existing system.
- Orders freeze server-owned prices and quantities. PayPal approval alone does not grant benefits. Capture, merchant, currency, amount and purchase reference are checked server-side; retries reuse the stored purchase and provider idempotency key. History and separate Bots+ cancellation live under Settings → Billing. Native/older Spark entry points resume the account-owned web checkout.
- Members have separated rows, room for decorated avatars and wrapped names/badges. The Owner crown follows the authoritative community OWNER role.
- Uploads need no photo-quality choice. Static JPEG/PNG/WebP photos are resized to a maximum 2560-pixel edge and encoded as WebP when useful and supported. Encryption/storage remain unchanged. Animations and unsupported/large formats retain their original bytes. Download converts static WebP to JPEG, or PNG when transparency requires it, with fallback to the original on unsupported browsers.
