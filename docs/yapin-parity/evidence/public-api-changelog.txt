			26 text Current version: 1.3.0 (the path stays /v1). Every answer carries X-Yapin-API-Version (the version) and X-Yapin-Build (the build that answered). GET /version tells you both plus the newest SDK versions, no token needed. Inside v1 we only add things: new endpoints, new fields, new events. Your bot should ignore fields it doesn’t know. Anything that would break a working bot gets a new /v2 path, announced ahead of time, and v1 keeps working. Every change is listed in the changelog. Features marked “In testing” work on test servers only and can still change.
