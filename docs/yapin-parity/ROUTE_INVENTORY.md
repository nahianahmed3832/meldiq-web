## Linked surfaces retained as limits

- `/download/windows` and `/download/linux`: binary download links observed; installers not downloaded or run.
- `/fankit/*`, `/sdk/*`, npm/PyPI packages and external database-rule GitHub links: destinations inventoried at their parent pages; source/assets not copied or executed.
- `/invite/developers` and other community invites: links observed; no external server joined.
- Other `/bot/{id}` profiles: directory and one profile sampled. Third-party descriptions are not independent Yapin functionality verification.
- Query combinations, documentation fragments and dynamic profile/conversation identifiers are states/instances, not additional inspected pages.
